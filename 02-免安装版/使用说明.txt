合资金账 FundMerge v4.9.2 · 免安装版（便携版）
=================================================

怎么用
------
1. 把整个 FundMerge-4.9.2-portable 文件夹解压/复制到任意可写目录
   （推荐 D:\软件\合资金账 或 U 盘根目录）。
2. 双击文件夹里的「合资金账.exe」即可运行，无需安装。

⚠️ 不要放在 C:\Program Files\ 或 C:\Program Files (x86)\ 下
   这些目录没有写权限，会导致数据保存失败。

数据在哪
--------
数据保存在「合资金账.exe 同级的 data 文件夹」里。
整个 data 文件夹就是你的账本，备份时整个复制走即可。

换电脑 / 备份 / 交接
--------------------
推荐用软件内的「设置 → 账套管理 → 导出账套」生成 .flpack 单文件，
到新电脑用「导入账套」还原。比复制 data 文件夹更可靠（含附件、含校验）。

⚠️ 不要把 data 文件夹放进 OneDrive / 坚果云同步文件夹 / Dropbox，
   同步客户端可能在写入中途上传，拿到半个 JSON 导致账本损坏。

功能说明
--------
本版与安装版功能完全一致（含账套包、云盘备份、附件、托盘）。
随包文档在同级 04-文档 文件夹，或在安装目录里也能找到。
