## 第一章 · 整体逻辑流程（优先展示）

本章先讲清楚"数据怎么存、钱怎么动、页面怎么跳、模块怎么关联"，后续每一章的具体测试都建立在这套流程之上。凡与本章口径不符的测试结果，一律按"发现的问题"处理。

### 1.1 数据模型（存什么）

系统是**单文件账套 + 多公司独立账本**结构。顶层一个 `DB` 对象（`version: 3`），一个账套里可容纳 N 家公司，每家公司有完全独立的账本数组，但共享一套用户、审计日志与全局设置。

```
DB（账套）
├── meta
│   ├── currency / fx { base, rates }      本位币 + 汇率表（多币种）
│   ├── groupName / activeCompanyId       集团名 + 当前选中的公司
│   └── voucherRule { reset, seqLen }     凭证号规则
├── users[]                                账号（id / username / role / companyIds / security）
├── auditLogs[]                            操作审计
└── companies[]                            每家公司一个独立账本
    └── Company
        ├── 基本资料（name / shortName / color / taxNo / note / isParent / profile）
        ├── accounts[]       账户：type = cash | bank | bill_pending | unreported
        │                      后两者为「系统账户」，只由票据流程维护
        ├── transactions[]   流水：type = in | out | transfer
        │                      transfer + peerCompanyId + pairId ⇒ 公司间转账（镜像一对）
        │                      noCash + fundedBy ⇒ 集团代付（由总公司出资）
        ├── debts[]          往来款：type = lend | borrow | reimburse
        ├── settlements[]    往来款结清记录
        ├── advances[]       借支备用金（发放 / 核销）
        ├── invoices[]       票据（付款待票 / 回票 / 报账）
        ├── budgets[]        月度预算
        ├── categories[]     收支分类（kind = in | out，含现金流口径 cf）
        ├── projects[]       项目
        └── parties[]        往来单位（客户 / 供应商）
```

关键规则：
- **角色**：`admin`（管理员）/ `staff`（记账员）/ `viewer`（查看员）。`can(perm)` 白名单控制写权限；查看员只读、写按钮禁用。
- **权限范围**：用户的 `companyIds` 决定能访问哪些公司（空数组 = 全部，仅管理员）。
- **归一化**：`normalize()` 在每次加载时补齐 id、修复脏数据（账户缺 id 补 `uid('a')`、用户缺 id 补 `uid('u')`），并做票据期初迁移，同时用 `NORMALIZE_REPAIRS` 计数供页面提示。

### 1.2 页面导航（怎么跳）

左侧导航分 6 组（来自 `NAV`，共 21 个导航项 + 2 个下钻页）：

| 分组 | 导航项 | 可见条件 |
|---|---|---|
| 集团 | 集团总览 · 资金看板 · 集团报表 | `multi`（≥2 家公司时显示） |
| 概览 | 公司总览 | 始终 |
| 账务 | 资金流水 · 往来款 · 借支备用金 · 票据未回 · 项目 | 始终 |
| 管理 | 公司档案 · 往来单位 · 账户管理 · 预算管理 · 分类管理 | 分类管理仅 admin |
| 报表 | 资金报表 · 凭证查询 | 始终 |
| 系统 | 公司管理 · 用户管理 · 操作日志 · 云盘备份 · 设置 | 前四项仅 admin |

- **下钻页**（不进导航，由其它页面按钮进入）：`drill`（指标下钻）、`flow-detail`（资金看板下钻）。
- **切换公司**：侧栏顶部的公司切换器，`switchCompany(id)` 改 `meta.activeCompanyId` 并重渲染；集团页（group / flowboard / group-reports）是跨公司视图，不绑定单一公司。
- **路由**：`UI.view` 状态 → `renderView()` → `renderShell()` 重建 DOM，`Scene3D.setView` 切换 3D 背景，`FlowBoard` 在看板页起停定时器。

### 1.3 资金流转（钱怎么动）

#### A. 单公司内（账户维度）

```
记一笔收入(in)  ──→ 目标账户余额 +
记一笔支出(out) ──→ 目标账户余额 −  ──→ 现金流 / 报表 / 预算
内部转账(transfer，同公司) ──→ 源账户 − 、目标账户 +（总额不变）
```

#### B. 公司之间（集团维度）

```
公司间转账：A 记一笔 transfer(out) + peerCompanyId，系统在 B 生成镜像 transfer(in)，
            pairId 成对。集团看板/报表只取「付款方那条」聚合，避免重复。

集团代付：B 记一笔支出，勾「集团代付」并选总公司 A 的出资账户，
           A 生成一条 noCash 记录（不计 A 现金余额，只计「代付给 B」）。
```

#### C. 票据流转（系统账户 = 中间桶）

```
登记未回票据(付款)  ──→  付款账户 − 、「票据未回资金」+
回票(整张回完)      ──→  「票据未回资金」− 、「未报账资金」+
报账(记费用分类)    ──→  「未报账资金」− 、费用支出（账面资金此时才减少）
撤销报账            ──→  逆向 + 写审计日志 + 二次确认
```

两个系统账户**只能随票据动作生成与结转**：不出现在任何手工记账下拉（统一走 `manualAccounts()`），账户页置顶只读，票据自动分录在流水页禁止编辑/删除（走「去票据」）。

#### D. 往来款 / 借支

```
往来款：lend(借出) / borrow(借入) / reimburse(员工未报销) + settlements(结清记录)
        → debtInfo 计算已结/未结/逾期；「往来款预期/待处理」洞察可下钻到对应公司+页签
借支：advances 发放（账户 −）→ 核销（部分/全额退回账户 + 费用）
```

#### E. 集团聚合口径（唯一来源）

- `groupTotals` / `groupSeries` / `groupCashFlow`：集团合并数。
- `groupFlowMatrix(from, to)`：**只统计**「公司间转账的付款方记录」与「集团代付」；同公司内部转账、对外收支不计；缺汇率跳过并提示（绝不 1:1 静默折算）。看板、流向明细、集团报表共用这一口径。

## 第一章（续）· 数据计算逻辑来源总表

> 本章逐一列出系统内每个数据项的计算公式与字段来源。代码位置均为 `assets/core.js`，公式中的 `round2` 表示四舍五入保留两位小数。

### 1.0 基础：本位币与汇率折算

| 数据项 | 公式 | 说明 |
|---|---|---|
| 汇率 `baseRate(cur, at)` | 取 `DB.meta.fx.rates[cur]` 中 `date ≤ at` 的最新一条 `rate`；同币种返回 `1`；无记录返回 `null`（缺汇率，绝不按 1:1 兜底） | `core.js:90` |
| 折本位币 `toBase(n, cur, at)` | `n × baseRate(cur, at)`；缺汇率返回 `null` | `core.js:105` |
| 单笔流水本位币 `txBase(t)` | `toBase(t.amount, 账户币种, t.date)`；孤儿流水（找不到账户）返回 `0` | `core.js:943` |
| 账户币种 `accCurrency(a)` | `a.currency`（缺失回落本位币） | — |

### 1.1 账户维度（现金 / 银行 / 系统账户）

| 数据项 | 公式 | 字段来源 |
|---|---|---|
| 账户余额 `balanceOf(acc, upto)` | `期初 openingBalance + Σ(收入 in) − Σ(支出 out) − Σ(转出 transfer) + Σ(转入 transfer)` | 逐笔流水：`type='in'` 加、`type='out'` 减、`transfer` 转出（`accountId=acc 且 direction≠in`）减、`transfer` 转入（`direction=in`）加、`transfer` 目标（`toAccountId=acc`）加 `toAmount>0 ? toAmount : amount` |
| 账户统计 `accountStats(acc, from, to)` | `opening = balanceOf(acc, from−1天)`；`inflow=Σ收入`；`outflow=Σ支出`；`transferIn=Σ转入`；`transferOut=Σ转出`；`closing = opening + inflow − outflow − transferOut + transferIn` | `core.js:969` |
| 区间统计 `rangeStats(from, to)` | `inflow=Σ收入(本位币)`；`outflow=Σ支出(本位币)`；`transfer=Σ转账(本位币)`；`net = inflow − outflow`；`count=笔数`；跳过 `noCash` | `core.js:950` |
| 总余额 `totalBalance(upto)` | `Σ balanceOf(账户, upto) × 汇率`（折本位币） | `core.js:914` |

### 1.2 现金流量表

| 数据项 | 公式 | 说明 |
|---|---|---|
| 现金流 `cashFlow(from, to)` | 按流水分类的 `cf` 口径聚合金额（跳过 `transfer` 与 `noCash`）；`经营/投资/筹资` 三大活动各 `net = 流入 − 流出`；`净额 = 经营净 + 投资净 + 筹资净`；`期末现金 = 期初现金 + 净额`；`期初现金 = totalBalance(from−1天)` | `core.js:992`，分类的 `cf` 字段决定归属 |

### 1.3 往来款

| 数据项 | 公式 | 说明 |
|---|---|---|
| 单笔往来 `debtInfo(d)` | `settled = Σ settlements(该笔).amount`；`remaining = d.amount − settled`；`status = remaining≤0.005 ? 已结清 : settled>0 ? 部分结清 : 未结`；`overdue = remaining>0.005 且 dueDate < 今日` | `core.js:1043` |
| 往来合计 `debtTotals(type)` | `total = Σ d.amount × 汇率`；`remaining = Σ (d.amount − settled) × 汇率`；`overdue = Σ 逾期remaining × 汇率`；缺汇率币种跳过并提示 | `core.js:1052` |

### 1.4 预算

| 数据项 | 公式 | 说明 |
|---|---|---|
| 预算行 `budgetRows(month)` | 对每个支出分类：`spent = Σ 该月该分类支出(本位币)`；`remaining = budget − spent`；`pct = spent ÷ budget × 100` | `core.js:1072` |
| 预算汇总 `budgetSummary(month)` | `budget = Σ 各分类预算`；`spent = Σ 各分类已用`；`remaining = budget − spent` | `core.js:1093` |

### 1.5 借支备用金

| 数据项 | 公式 | 说明 |
|---|---|---|
| 借支 `advanceInfo(a)` | `used = Σ draws.used`（无 draws 时取 `usedAmount`）；`back = Σ draws.back`；`remain = a.amount − used − back`；`status = remain≤0.005 ? 已核销 : 已发放` | `core.js:1780` |

### 1.6 票据资金（系统账户）

| 数据项 | 公式 | 说明 |
|---|---|---|
| 票据资金 `invoiceFund(co)` | `pending = balanceOf(票据未回账户) × 汇率`；`unreported = balanceOf(未报账账户) × 汇率` | 两个系统账户的余额即「票据未回 / 未报账」金额 |

### 1.7 公司维度

| 数据项 | 公式 | 说明 |
|---|---|---|
| 公司资金合计 `companyBalanceAt(co, upto)` | 按账户币种分桶：`bucket[cur] = Σ openingBalance + Σ(收入) − Σ(支出)`（跳过 transfer 与 noCash）；`total = Σ bucket[cur] × baseRate(cur, upto)` | `core.js:1105`，单遍扫描 |
| 公司合计 `companyTotals(co, upto)` | `total = companyBalanceAt`；`cash = Σ cash型账户余额×汇率`；`bank = Σ bank型账户余额×汇率`；`billPending = Σ 票据未回账户×汇率`；`unreported = Σ 未报账账户×汇率`；`receivable(应收) = debtTotals('lend').remaining`；`payable(应付) = debtTotals('borrow').remaining + debtTotals('reimburse').remaining` | `core.js:1132` |

### 1.8 集团维度

| 数据项 | 公式 | 说明 |
|---|---|---|
| 集团合计 `groupTotals(upto)` | `total/cash/bank/billPending/unreported = Σ 各公司对应值`；`receivable = Σ 各公司应收`；`payable = Σ 各公司应付` | `core.js:1159` |
| 集团序列 `groupSeries(from, to)` | 逐日/隔步 `Σ companyBalanceAt(各公司, 该日)` | `core.js:1176` |
| 集团现金流 `groupCashFlow(from, to)` | `Σ 各公司 cashFlow 按 cf 分类聚合`；`净额 = 三活动净额之和`；`期末 = 期初 + 净额` | `core.js:1190` |
| 集团流转矩阵 `groupFlowMatrix(from, to)` | 只取「公司间转账 out 腿」（pairId 去重）+「集团代付」（noCash，来源 = fundedBy）；`transferTotal = Σ 转账边金额`；`payTotal = Σ 代付边金额`；`totalFlow = transferTotal + payTotal`；节点 `inflow/outflow` 为收/付合计、`balance = companyBalanceAt(区间末)` | `core.js:1228` |

### 1.9 指标下钻

| 数据项 | 公式 | 说明 |
|---|---|---|
| 下钻 `drillRows(metric)` | `total/cash/bank = companyTotals 对应字段`；`net = receivable − payable`；`lend = receivable`；`pay = payable`；`monthIn/monthOut = rangeStats(本月).inflow/outflow` | `core.js:2020` |

### 1.10 关键口径结论

- **账面资金 = 各账户余额之和**，账户余额由「期初 + 收入 − 支出 ± 转账」逐笔累计，不含 `noCash` 镜像分录。
- **集团资金总额 = 各公司资金合计之和**（转账只在公司内部搬账户，不改变集团总额）。
- **集团内流转 = 公司间转账（付款方腿）+ 集团代付**，绝不含单公司内部转账，也绝不重复计镜像。
- **应收 = 借出款未结**；**应付 = 借入款未结 + 员工未报销**。
- **票据未回 / 未报账 = 两个系统账户的余额**，由票据登记/回票/报账动作结转。
