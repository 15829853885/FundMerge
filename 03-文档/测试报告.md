## 七、复现方式

本轮用例在真实 Electron 渲染进程中执行，关键步骤：

```js
// 1. 起一个静态服务器指向工程根，BrowserWindow 加载 index.html
// 2. 注入数据（本位币 GHS + USD 汇率 12 + 一条孤儿流水）
DB.meta.fx = { base:'GHS', rates:{ USD:[{ date:'2026-01-01', rate:12 }] } };
// 3. 断言
txBase(t1) === 1200;                 // 正常折算
txBase(t2) === 0;                    // 孤儿流水排除
companyBalanceAt(co) === 1200;       // 合计不含孤儿
dataQualityIssues()[0].kind === 'orphan-tx';
// 4. 主进程纯函数
require('./electron/flpack.js').inspectWarnings(ledger);  // 四类计数
```

页面回归：`startSession(role)` → `renderShell()` → 逐个 `UI.view = v; renderView()`，检查 `#view-root` 非空且无 `error` 事件。

## 八、结论

- **数据正确性**：本轮最重的一条（DEF-07）已修。改动后"算不出来"的流水会被**排除并告知**，而不是"按 1:1 算个错的数"。这与项目既有的「缺汇率绝不静默折算」原则一致。
- **权限**：查看员角色从"建得出来但保不住"变成"建得出、保得住、写不了"。
- **回归**：60 次页面渲染、多币种折算、集团口径、登录注册均无退化。
- **仍需人工**：安装向导、视觉走查、真实数据试跑（见第六节与《收尾交付说明》验收路径）。
