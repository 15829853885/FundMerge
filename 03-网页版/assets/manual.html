一、安装、启动与卸载

1.1 系统要求

项目要求
操作系统Windows 11 / Windows 10，64 位
磁盘空间安装约 360 MB，数据另计（附件越多占用越大）
网络不需要。软件完全离线运行
权限按当前用户安装，无需管理员权限

1.2 安装步骤

安装
  1. 双击 FundLedger-Setup-x.x.x.exe。
  2. 若出现蓝色「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。 这是未购买代码签名证书导致的正常提示，不是病毒。
  3. 在安装向导里点「浏览」选择安装位置（可装到 D 盘等非系统盘）。
  4. 点「安装」，等待完成；勾选「运行合资金账」可直接启动。
数据就在安装目录里。安装到 D:\合资金账，数据就在 D:\合资金账\data。 选择安装位置时请预留足够空间，并避开需要管理员权限才能写入的目录（如 C:\Program Files）。

1.3 首次启动

启动后直接进入登录页。系统已内置最高管理员账号（见 第二章），用它登录即可开始使用。

默认会有一家名为「我的公司」的空账本，请先在「设置 → 公司与货币」里改成真实公司名，或直接新建公司。

1.4 升级安装

新版安装包直接双击覆盖安装即可，安装目录下的 data 文件夹不会被删除，账号与账目全部保留。

升级前建议先复制一份 data 文件夹做备份，以防万一。

1.5 卸载

卸载会删除安装目录，包括 data 文件夹！ 卸载前务必先把 data 文件夹复制到别处。卸载后重新安装时，把 data 文件夹放回安装目录即可恢复全部数据。

二、登录与账号

2.1 登录

输入账号与密码，点「登录」。登录前需先选择登录身份。

登录身份：下拉选择「记账员 / 查看员 / 管理员」，管理员固定排在最后一项。所选身份必须与该账号的实际角色一致，否则会提示「该账号是「X」，请选择正确的身份后重试」。系统会按账号记住你上次选择的身份，下次用同一账号进入登录页自动回填；首次登录某个账号时，会先自动预置该账号的真实身份，你仍可手动改。若选了与账号不符的身份，会提示「该账号是「X」」并自动切到正确身份，需要再点一次「登录」。
登录公司：输入账号后，「登录公司」下拉会自动列出该账号被授权的公司，选一家进入。 管理员可看全部；记账员 / 查看员只能选被授权的（可在「用户管理 → 可操作公司」里配置，支持授权多家）。
  • 记住账号：勾选后下次自动填入账号，不会保存密码。
  • 密码连续输错不会锁定，但请勿在公共电脑上勾选「记住账号」。

2.2 内置最高管理员（首次使用设置口令）

程序内置一个最高管理员账号（初始账号名 owner，可在首次使用时改成你自己的手机号或易记账号）， 用于首次初始化。该账号不能被删除或降级。

第一次启动
  1. 打开软件，会进入「首次使用」页面；
  2. 为该账号设置登录口令（至少 6 位）并确认；
  3. 设置两个预留问题与答案（忘记口令时自助找回用）；
  4. 点「保存并进入」，用刚设置的口令登录。
程序里不包含任何默认口令。口令只保存在本机数据文件中（加盐哈希）。 口令与预留答案请自行妥善保管——忘记且无预留信息时，只能由其他管理员重置。
建议首次登录后立刻到「设置 → 账号安全」再改一次口令，并记住预留答案。

2.3 注册账号

登录页点「注册账号」。各字段要求：

字段规则
登录账号3–20 位，只能是字母、数字或 _ . -；不能与已有账号重复
显示名称姓名或昵称，会显示在流水「经办人」和右上角
登录密码至少 6 位
确认密码必须与上一行一致
注册用户类型必选，只能选「记账员」或「查看员」；不选或传入非法值会提示错误并阻止提交
预留问题 1/2从 6 个预设问题中选择，两题不能相同
答案 1/2必填，不区分大小写，忽略多余空格

注册成功后自动登录，角色为你选择的记账员或查看员。管理员角色不能自助注册，需由管理员在「用户管理」中创建或改派。

2.4 忘记密码

三步找回
  1. 登录页点「忘记密码」，输入账号，点「下一步」。
  2. 页面显示该账号设置的两个预留问题，填写答案后点「验证身份」。
  3. 验证通过后设置新密码（至少 6 位，两次一致），点「重置密码」，返回登录页用新密码登录。
遇到的情况处理方式
提示「账号不存在」检查账号拼写，注意不要带空格
提示「第 N 题的答案不正确」按提示只改那一题；答案不区分大小写，但字要一致
提示「该账号没有设置预留信息」找管理员在「用户管理 → 重置密码」直接设新密码
提示「该账号已被停用」让管理员在用户管理中重新启用

2.5 修改密码与预留信息

登录后点右上角头像 →「修改密码」，需先输入当前密码。

「设置 → 账号安全 → 设置/修改预留信息」可随时重设两个问题与答案。修改后旧答案立即失效。

2.6 退出登录

头像菜单 →「退出登录」。退出只是回到登录页，数据不会丢失；关闭软件后下次启动也需要重新登录。

四、公司管理与集团总公司

4.1 新建公司

操作
  1. 左侧切换器 →「新建公司」，或「公司管理 → 新建公司」。
  2. 填写公司名称（必填）、简称、税号/注册号、标识色、备注。
  3. 点「创建公司」，系统会自动切换到新公司并进入其总览页。

新公司自带一套独立的：账户（空）、28 个默认分类、流水（空）、往来（空）、预算（空）、档案（空）。

4.2 编辑公司

「公司管理 → 编辑」可改名称、简称、税号、标识色、备注，以及「设为集团总公司」开关。

4.3 集团总公司

勾选「设为集团总公司」后，这家公司承担两个特殊角色：

  1. 持有集团资金，可以向任何子公司拨款；
  2. 为子公司代付：子公司记账时可以直接选总公司的银行账户付款。
全集团只能有一家总公司。给新公司勾选后，原来那家会自动取消。

4.4 删除公司

删除公司会同时删除：该公司的账户、流水、往来、预算、分类、档案记录，以及 data\files\ 下对应的文件夹。不可恢复，操作前请先导出备份。

至少保留一家公司，最后一家不能删除。删除时当前登录的公司若被删，会自动切到剩下的第一家。

4.5 集团名称

「设置 → 集团信息」填写集团名称（如「刘氏集团」）。会显示在：集团总览大标题、左侧切换器、登录页副标题。

4.6 总公司登记方式（可配置）

「设置 → 集团总公司登记方式」有两种模式：

模式含义
作为独立公司总公司的资金、往来计入集团总额与集团报表（默认）
仅集团登记主体总公司只作集团主体登记，不参与集团合并计算
切换会改变集团总额与集团报表的口径。已有数据不会删除，切回来即恢复。切换会记入操作日志。

场景：公司 2026 年 1 月 1 日开始用软件，Ecobank 账上还有 268,000。 正确做法：期初余额填 268000，期初日期填 2026-01-01，然后只录入 1 月 1 日之后的流水。

5.2 余额计算规则

当前余额 = 期初余额 + 收入 − 支出 − 转出 + 转入
内部转账只改变账户余额，不影响收入/支出统计与现金流量表。

5.3 对账调整

操作

  2. 填入银行对账单上的实际余额。
  3. 系统显示差额（如 +12.00 或 −35.00），点「生成调整流水」。

会生成一笔分类为「余额调整」的流水，不影响经营收支统计，只修正余额。

七、集团资金：代付、互转与拨款

7.1 先理解三种资金动作

动作钱从哪到哪账务结果
集团代付总公司账户 → 外部供应商子公司记费用但余额不变；总公司余额减少，并生成一条「对子公司代付」
公司间转账任意公司账户 → 任意公司账户双方各记一笔等额转账，两边余额同步变化，集团总额不变
拨款总公司账户 → 子公司账户就是「公司间转账」，只是方向固定为总公司出、子公司进

7.2 集团代付（子公司花钱，总公司付钱）

操作
  1. 进入子公司，点「记一笔」，类型选「支出」。
  2. 「付款账户」下拉里有两组：
    「本公司账户」——自己付；
    「总公司名（集团代付）」——总公司付。
  3. 选总公司账户，填金额、分类、摘要，保存。
看到的现象解释
子公司余额没变正常。钱不是从子公司账户出的
子公司这条流水带「集团代付」标签账户列显示为「总公司 · 账户名」
子公司支出统计、预算里算进去了费用归属子公司，这是对的
总公司余额减少了总公司账上自动多出一条「对子公司代付」
集团资金总额只减少一次不会重复计算
只有「支出」能选总公司账户。收入、内部转账不支持代付。

7.3 公司间转账（任意两家公司互转）

操作
  1. 方式一：集团总览 →「公司间转账」；
    方式二：进入任一家公司 →「记一笔」→ 类型选「内部转账」。
  2. 「转出账户」选本公司账户。
  3. 「转入账户（可跨公司）」里选择目标公司下的账户（列表按公司分组）。
  4. 填金额与日期，保存。

系统会在两家公司各生成一笔金额相等的记录，带同一个内部编号：

  • 转出方：一条「转出」，减少该账户余额；
  • 转入方：一条「转入」，增加该账户余额；
  • 两笔都不计入收支统计与现金流量表，所以集团总额不变。
公司间转账不支持直接编辑（会影响对方账本）。要改金额请删除后重录； 删除其中一笔，对方那笔会自动一起删除。

7.4 集团拨款

拨款就是「公司间转账」，操作同上：转出账户选总公司账户，转入账户选子公司账户。 摘要建议写清用途（如「3 月运营拨款」），方便子公司对账。

9.1 设置预算

操作

  • 进度条：绿色 <80%，黄色 80–100%，红色 >100%；
  • 「剩余」列为负数时表示超支金额；
  • 顶部卡片显示预算总额、已使用、剩余、使用率。

点「复制上月预算」，会把上月每个分类的金额复制到本月（已设置的不覆盖）。适合每月预算基本固定的情况。

9.4 超支提醒

本月有分类超预算时，公司总览的「关注提醒」会出现一条，点「看预算」直达。

9.5 自动生成预算（重点）

不用每个月手工填，可以让系统根据最近几个月的实际支出自动推算。

操作
  1. 进入「预算管理」，点工具栏的「自动生成」；
  2. 选目标月份、参考周期（近 3 / 6 / 12 个月）、算法；
  3. 弹窗里逐项显示：近 N 月支出、月均、建议金额、可改的最终预算；
  4. 不满意可以直接改某一项的金额，合计会实时更新；
  5. 点「写入预算」，一次性写入并留一条版本记录。

四种算法怎么选

算法适用场景计算方式
历史平均支出比较稳定近 N 月支出之和 ÷ N
历史中位数有偶发大额，怕被拉高取中间值，抗极端值
近期加权（默认）支出有缓慢变化越近的月份权重越大（1:2:3…）
趋势外推支出在持续上升或下降最小二乘拟合直线，预测下一个月（不会为负）

其它参数

  • 调整幅度 %：在算法结果上整体上浮/下调，比如填 10 就是加一成；
  • 取整到：把结果取整到 10 / 100 / 1000，方便看；
  • 最低预算：低于这个数的分类按这个数算，避免出现 0 或很小的数；
  • 没有任何支出的分类默认跳过（不生成）。
生成结果会覆盖目标月份已有的同分类预算，但不影响其它分类。 每次生成都会记一条版本（时间、算法、参数、各项金额），预算页会显示「最近一次由 X 生成于 Y」。

9.6 数据校验规则

所有表单在提交前都会做统一校验，不合格的字段变红 + 抖动 + 下方给出原因，并自动滚动定位。

校验类型规则
必填收付款的往来单位、摘要、经办人、金额；往来单位名称；项目名称；借支员工与金额
格式日期必须是 YYYY-MM-DD；电话只能含数字、空格、+、-、括号；税号只能含字母数字和 -
金额必须大于 0，最多两位小数，单笔上限 1000 亿
长度单位名称 2–50 字、项目名称 2–60 字、摘要 ≤120 字、凭证号 ≤40 字
重复往来单位名称、项目名称不能重名；凭证号不能重复

校验不通过时表单不会关闭，改完再提交即可。

十二、导入与导出

12.1 导入资金明细（补录历史）

用于「很长一段时间没记，现在要把以前的账补进去」。

操作
  1. 进入目标公司 →「资金流水」→ 工具栏「导入」。
  2. 首次使用先点「下载模板」，得到 资金明细导入模板.csv。
  3. 用 Excel 打开模板填写，另存为 CSV（逗号分隔）。
  4. 回到软件点「选择文件」，选中 CSV。
  5. 预览窗口显示「可导入 N 条 / 问题 M 条」，核对无误后点「导入 N 条」。

模板列说明

列是否必填格式与说明
日期必填支持 2026-01-05、2026/1/5、20260105
类型必填收入 / 支出 / 内部转账（也认 in、out、transfer）。留空按「支出」处理
分类收支必填写分类名称。不存在的分类会自动创建；转账不需要填

校验与异常

提示处理
日期「xxx」无法识别改成 2026-01-05 这类格式
金额「xxx」不正确必须是大于 0 的数字

操作

十二·五、业务模块：往来单位 / 借支 / 票据 / 凭证

12b.1 往来单位

菜单：管理 → 往来单位。把常用客户、供应商建成档案。

字段说明
单位名称必填，不能重名（重名会拦下并高亮输入框）
类型客户 / 供应商 / 其他

12b.2 借支备用金

菜单：账务 → 借支备用金。

三步流程
  1. 申请：填员工、金额、日期、事由，状态为「待发放」；
  2. 发放：选付款账户，确认后自动生成「借支发放」支出流水，状态变「已发放」；
  3. 核销：填实际已用金额，余额可退回指定账户（自动生成「借支退回」收入流水），状态变「已核销」。
已用金额不能超过借支金额；余额为 0 时可不选退回账户。顶部卡片显示「已发放未核销」总额与「待核销余额」。

12b.3 票据未回

菜单：账务 → 票据未回。付款后发票迟迟不到，先登记下来避免漏票。

  • 记录：往来单位、金额、付款日期、预计回票日、实际回票日、备注；
  • 状态：未回 / 部分回 / 已回；
  • 超过预计回票日且未回，列表标「逾期」，顶部统计逾期张数；
  • 顶部「未回票据金额」汇总所有未回票据。

12b.4 凭证查询与凭证号

菜单：报表 → 凭证查询。按凭证号、日期、摘要、往来单位检索全部单据。

凭证号规则：前缀-年月-4位流水，例如 付-202610-0001。
前缀：收入 收、支出 付、转账 转；按月重置流水号。
记账时留空会自动生成，也可点「自动」按钮手动触发。

列表显示凭证号、日期、类型、分类、摘要、往来单位、金额、所属公司，可导出 CSV。

12b.5 项目（按资金使用归集）

菜单：账务 → 项目。项目用来回答「这笔钱是花在哪个项目上的」。

  • 建项目：名称（不能重名）、编号、状态、预算、开始日期；
  • 记账时「归属项目」下拉可选，选完这笔流水就归到该项目；
  • 项目页自动统计：预算、已支出、剩余、执行率进度条、流水笔数；
  • 超预算时剩余金额标红、进度条变红；
  • 已有流水的项目不能删除，避免统计口径断裂。

12b.6 集团指标下钻

集团总览的四个指标卡（集团资金总额 / 库存现金 / 银行存款 / 往来账款净额）都可以点。

下钻路径
  1. 点击指标卡 → 进入该指标的「各公司构成」页；
  2. 页面显示每家公司金额、占比、对比条；
  3. 点「查看明细」→ 直接切到该公司的资金流水；
  4. 顶部面包屑「集团总览 › 指标名」，可一键返回。

十四、设置

设置页分左右两栏：通用设置（集团、本位币、外观与数据概况）与 数据与安全（安全策略、账套、备份与账号）。

设置页中会改动账本数据的操作（集团名称、本位币、自动退出时间、总公司登记方式、数据目录、汇率录入）在保存 / 生效前须先验证当前管理员密码；主题、动效、流畅度属本地偏好，即时生效、无需密码。

14.1 集团信息

「集团名称」显示在集团总览标题、左侧公司切换器、登录页副标题，用于标识多家公司合并后的整体。填好后点「保存集团名称」，可点「查看集团总览」跳转。

14.2 集团总公司

集团自身也是一家公司，可独立登记注册信息、银行账号与证照。指定后，集团总览与集团报表才能区分「总公司自身」与「含下属公司」。

  • 未指定时：提供「创建集团公司」（新建一家代表集团的公司）与「把现有公司设为集团公司」两个入口；
  • 已指定时：显示集团名称、账户数、登记方式，并提供「进入集团账本」「编辑集团档案」「改公司信息」；
  • 登记方式（切换需二次确认 + 管理员密码）：作为独立公司参与合并（其资金与往来计入集团合计）或 仅作集团登记主体（不计入，避免集团内部资金重复计算）。

14.3 本位币与汇率

本位币是所有汇总与报表的计量单位（默认塞地 ₵，可换人民币 ¥ / 美元 $ / 欧元 €）。账户可挂不同币种，跨币种汇总时按下方录入的汇率折算，原币金额始终保留。下方「汇率」列表按币种列出当前汇率 / 最后录入时间与操作人 / 录入汇率按钮，点「录入汇率」填写新值（只增不改、历史留痕、需管理员密码）。

缺汇率的外币账户不计入汇总，相关页面会提示「未折算」，不会按 1:1 静默折算。

14.4 外观主题

浅色 / 深色 / 蓝色三档，点色块即时生效并记住选择。深色主题下图表、弹窗、3D 氛围层会自动切换为配套配色。

14.5 页面动效

  • 开关：关闭后所有入场动画与过渡立即停用，界面即时响应；
  • 速度档位：慢 / 标准 / 快，统一影响全站动效时长；
  • 系统开启「减少动效」时自动降级为淡入淡出。

14.6 界面流畅度

自动（检测显卡加速，无则降级）/ 流畅优先（关闭 3D 氛围层与入场动画）/ 效果优先（全部开启）。虚拟机、远程桌面、老驱动建议「流畅优先」。

「自动退出（分钟）」：长时间无操作自动退出登录，避免离开工位后账号被他人使用。保存需管理员密码。

14.9 账套管理

14.10 数据目录

十六、常见问题（30 问）

1. 忘记登录密码怎么办？

登录页「忘记密码」，用预留问题重置。没设预留信息就找管理员在「用户管理 → 重置密码」重设。

2. 忘记最高管理员密码怎么办？

如果其它管理员还能登录，让他重置；如果都不行，只能联系软件提供方，用数据文件重置（需要能访问 data 目录）。

3. 为什么左侧没有「集团总览」？

只有一家公司时不显示集团菜单。新建第二家公司后自动出现。

4. 为什么看不到「分类管理」「用户管理」？

当前账号是记账员，这两个页面只有管理员可见。

5. 为什么删不掉某个分类？

该分类已被流水使用。可以编辑它并取消「启用」，历史数据保留，只是不再出现在新记账的下拉里。

6. 为什么删不掉某个账户？

该账户已有流水。改成「停用」即可。

7. 期初余额填错了怎么办？

账户管理 → 编辑，直接改期初余额；或用「对账调整」生成一笔差额流水。前者会改写历史余额，后者留下调整痕迹，推荐后者。

8. 子公司付了钱，为什么子公司余额没变？

付款账户选的是「集团代付（总公司账户）」，钱从总公司出。子公司的费用记了，余额自然不变。详见 7.2。

9. 公司间转账后，为什么收支统计里看不到？

公司间转账属于资金调拨，不是收入也不是支出，所以不计入收支与现金流量表，只改余额。

10. 公司间转账能改金额吗？

不能直接编辑。请删除后重录（删除会同时删掉对方那笔）。

11. 导入时提示「账户不存在」？

CSV 里的账户名必须和「账户管理」里的名称一字不差（含空格）。先去建账户，或把 CSV 里的名字改对。

12. 导入会不会重复？

日期、类型、金额、摘要、账户都相同的行会被判为重复并跳过，同一文件传两次是安全的。

13. Excel 另存 CSV 后中文乱码？

请选「CSV UTF-8（逗号分隔）」格式；软件读取时会自动去掉 BOM。

14. 金额颜色为什么是红进绿出？

沿用国内财务习惯：红色代表流入/应收，绿色代表流出/应付。

15. 内部转账会影响报表吗？

不会。内部转账只改账户余额，不进收支统计和现金流量表。

16. 一张凭证付了多个分类怎么办？

拆成多笔流水录入，凭证号填同一个，便于日后按凭证号检索。

17. 银行扣了手续费没记账，余额对不上？

用账户的「对账调整」，填实际余额，系统自动补一笔「余额调整」流水。

18. 能改已记账流水的日期吗？

可以，编辑里改日期即可，相关报表会重新计算。

19. 删除流水能恢复吗？

不能。删除前会二次确认；重要数据请定期备份 data 文件夹。

20. 卸载后数据还在吗？

不在。卸载会删除安装目录，包括 data。卸载前务必先复制 data 文件夹。

21. 升级会丢数据吗？

不会。覆盖安装不会删除 data 文件夹，但建议升级前备份一次。

22. 数据会上传到网上吗？

不会。软件不联网，数据只在本机；除非你自己把 data 放进网盘。

23. 两台电脑能同时用吗？

不建议同时打开。网盘同步是文件级的，同时写入会冲突。正确做法见 15.4。

24. 出现 data.conflict 文件是什么？

检测到其它设备同时修改了数据。该文件保存了被覆盖的那一版，请打开核对后决定保留哪份。

25. 附件上传失败？

检查：文件是否被其它程序占用、磁盘是否已满、文件名是否含特殊字符。可换个位置再试。

26. 附件在列表里点「打开」没反应？

文件可能被移动或删除了。点「刷新时间」看是否还在；不在的话重新上传。

27. 打印出来是空白/排版乱？

请在报表页点「打印」，不要用浏览器打印；打印前把窗口最大化。

28. 货币符号不对？

设置 → 通用设置 → 本位币与汇率，选择本位币。切换只改符号与报表口径，不做汇率换算。

29. 软件打开很慢/卡顿？

先关闭其它占用资源的程序；若显卡驱动较旧，软件会自动降级为软件渲染（首次崩溃后下次启动生效）。

30. 想彻底重来怎么办？

设置 → 数据与安全 → 示例与重置 →「清空全部数据」清空账本（保留账号）；或卸载后删除 data 重新安装。

31. 顶部菜单栏（文件/编辑/视图/帮助）不见了？

为了界面简洁，菜单栏已隐藏。常用操作用快捷键：Ctrl+N 记一笔、Ctrl+S 备份、Ctrl+O 恢复；需要时按 Alt 可临时唤出。

32. 侧边栏怎么折叠？

两种折叠：点侧边栏顶部标题旁的按钮可把整条侧边栏收起为窄条（只留图标）；点某个分组标题（带下箭头）可单独收起该组菜单。折叠状态会被记住，刷新或切换公司后保持；当前所在页面的分组始终展开并高亮。

33. 列表每页显示多少条能改吗？

能。每个列表底部的分页栏有「每页」下拉框（15 / 30 / 50 / 100），改后自动回到第一页并记住。

34. 设置页为什么有些操作要输密码？

会改动账本数据的操作（集团名称、本位币、自动退出时间、总公司登记方式、数据目录、汇率录入）须先验证当前管理员密码；主题、动效、流畅度属本地偏好，即时生效、无需密码。

35. 「集团总公司」标识在哪显示？

指定集团总公司后，其公司名后带紫色「集团总公司」徽标，在公司管理、公司档案、集团总览、集团报表、指标下钻等页面统一显示。

36. 深色主题怎么开启？

设置 → 通用设置 → 外观主题，点「深色」即可；图表、弹窗、3D 氛围层会自动切换为配套配色。

十八、v5.0 新增功能（2026-10）

本章只讲 v5.0.0 相对 v4.9.x 的变化。老功能的使用方式不变。

18.1 多币种与汇率

v5.0 起，每个账户可以有自己的币种，全站汇总按「本位币」计量。

怎么用
  1. 「设置 → 本位币与汇率」选本位币（默认塞地 GHS）；
  2. 同一区块下方录入外币汇率：1 外币 = ? 本位币，选生效日期；
  3. 建账户时选「账户币种」，期初余额按该币种填；
  4. 账户列表会同时显示原币金额与折算后的本位币金额。

缺汇率会怎样：该外币账户不计入汇总，页面顶部会出现橙色提示条「有 N 种外币缺少汇率」，点「去录入汇率」直达设置页。系统不会按 1:1 静默折算，避免错账。

汇率留痕：每次录入都追加一条记录（含录入人与时间），历史报表按各自日期的汇率折算，改汇率不会改写已发生的历史口径。

18.2 跨币种转账

从 GHS 账户转到 USD 账户时，转账表单会多出「到账金额（转入账户币种）」一栏，系统按当日汇率自动预填，你可以手动改。

结果
  • 转出账户按转出币种扣款；
  • 转入账户按「到账金额」入账；
  • 公司资金总额不变（同一笔钱换了币种）。

18.3 往来款的计价币种

登记往来款时可以选「计价币种」。借出 1000 美元、账户是塞地时，结清会自动按汇率折成塞地入账。

往来台账的「金额 / 已结 / 未结」显示原币，外币记录下方会附一行「≈ 本位币金额」。顶部的应收 / 应付合计则是折算后的本位币。

18.4 资金对账单

「报表 → 资金对账单」，一页看清资金全貌：

构成项说明
库存现金所有现金类账户余额合计
银行存款所有银行类账户余额合计
票据未回未回 / 部分回票据的剩余金额
借款借入未还 + 员工未报销
借支备用金已发放未核销的余额
总账面金额以上五项之和

每一项都有「查看明细」按钮，直接跳到对应台账并带好筛选。注意：只有「现金 + 银行」是能动的钱，后三项是往来占用。

18.5 借支支持分次核销与撤销

分次核销
  1. 借支行点「核销」；
  2. 填「本次实际使用金额」（可以小于剩余）；
  3. 不勾「同时把未用完的余额全部退回并结清」→ 只登记本次，余额继续挂着；
  4. 勾上 → 剩余部分退回所选账户，该笔结清。

核销记录会累加，表格里的「已用 / 余额」实时反映。核销错了点行末的撤销按钮（逆时针箭头），会撤销最近一次核销，并连带删除那次生成的退回流水。

18.6 票据快捷回票

票据行新增「回票」按钮，不用再打开编辑弹窗：

  1. 选「全部已回」或「部分已回」；
  2. 部分已回时填本次金额；
  3. 选回票日期，输入随机数字确认。

系统按累计已回金额自动判定状态：累计达到票面 → 已回；否则 → 部分回。

18.7 公司档案：账号卡片

「公司档案 → 账号卡片」可以一次录完一个账号的全部信息：户名、账号、开户行、网银地址、网银用户名、网银密码。留空的项不会生成空条目。

保存后这些字段归入「银行账户」分组，标签形如「Ecobank 对公账户 · 网银密码」，便于识别。原有的「快速添加」仍保留，用于单项补充。

18.8 台账筛选与分页

往来款、借支备用金、票据未回三个台账都增加了筛选栏：

  • 日期范围（开始不能晚于结束，否则会拦下并标红）
  • 状态（未结清 / 部分 / 已结清等）
  • 关键字（对方名称、备注、票号、员工姓名）
  • 「清空筛选」一键复原；每页 15 条，底部翻页

台账顶部的指标卡也可以点：点「未结清」只看未结清，点「逾期」只看逾期，点「全部」清空筛选。

18.9 全面下钻

可点击的位置（都有手型光标）：

位置点进去看到
集团总览：资金总额 / 现金 / 银行 / 往来净额各公司构成 → 再进某公司流水
集团总览：本月流入 / 流出本月各公司流入 / 流出构成
集团报表：资金总额 / 应收 / 应付各公司构成
公司总览：本月净流入 / 应收 / 应付本月流水 / 借出台账 / 借入台账

下钻进去的流水会自动带上来源筛选（比如从「本月流入」进来就是本月 + 收入），不用再手动筛一遍。

18.10 分级二次确认

为防误操作，修改类操作会二次确认，但强度分级：

操作确认方式
改金额、删除、改状态、清空数据输入 4 位随机数字
改备注、改设置、保存汇率普通确认框
新增不弹确认

输错可以无限重试，取消则不做任何变更。

18.11 操作日志：备注与删除

日志的原始字段（时间、用户、对象、变更前后）不可编辑，但可以：

  • 加备注：点铅笔图标，写入备注并记录备注人与时间；
  • 删除：点垃圾桶，输入随机数字后逻辑删除——记录本身保留，勾选顶部「显示已删除」仍可查看。

18.13 集团总公司：怎么创建、怎么登记集团资料

v5.0.1 起，集团总公司有了显式入口。此前只能在公司编辑弹窗里勾一个不显眼的复选框，很多人根本找不到，于是出现「选了模式但看不到集团公司」的困惑。

创建集团公司（二选一）
  1. 设置 → 集团总公司 → 点「创建集团公司」，填名称/简称/税号，勾「同时把集团名称设为该公司名称」；
  2. 或者点「把现有公司设为集团公司」，从列表里挑一家，原账本数据不受影响。

创建完会直接进入公司档案，可以在这里补：注册地址、联系方式、银行账号、网银凭证、证照附件。这份档案同时也代表集团本身，页头会标「集团总公司」。

三个入口都能到集团档案
  • 设置 → 集团总公司：「进入集团账本」「编辑集团档案」「改公司信息」
  • 公司管理：顶部「集团总公司 · 自身账本」卡片，含账户数/流水数/档案字段/附件数
  • 集团总览：页头右上「集团档案」按钮

要不要计入合并？在「设置 → 集团总公司」里切换：

  • 作为独立公司参与合并：总公司的账户与流水计入集团合计（适合集团本身也在实际经营）；
  • 仅作集团登记主体：账户与流水照样能记，但不计入集团合计，避免集团内部资金重复计算（适合集团只是持股平台）。

切换后集团总览、集团报表、公司管理三处的合计口径会同步变化，无需手动调整。

18.14 界面流畅度（v5.0.1 新增）

「设置 → 界面流畅度」三档，解决「动效看着卡」的问题。它和上面的「页面动效」开关是两件事：动效开关管要不要动，流畅度管动起来会不会卡。

档位行为
自动（默认）启动时问系统要显卡状态。检测到硬件加速 → 用完整效果；检测不到（虚拟机、远程桌面、老驱动）→ 自动降级为流畅模式
流畅优先关闭 3D 氛围层、入场淡入、表格逐行动画、悬停抬升与阴影、装饰光晕。界面切换变成瞬时完成
效果优先全部开启，适合显卡正常的机器

设置页会显示当前生效状态，例如「自动（未检测到显卡加速，已降级为流畅模式）」。切换后立即生效，不需要重启。

18.12 集团总公司：双段式展示

当总公司被设为「仅作集团登记主体」时，集团总览会把总公司单独放在最上方一张卡里，标注「不计入下方合并合计」；下方才是参与合并的分公司网格。

集团报表的合计行下方会多一行「其中：总公司自身（不计入合计）」，方便核对两个口径。卡片上可直接点「改为参与合并」切换。
