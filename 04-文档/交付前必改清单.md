# 交付前必改清单（FundMerge）

> 适用版本：v5.0.0+ ｜ 整理日期：2026-10-29
> 用途：每次发版前逐项打勾。**这份清单的存在理由**——v5.0.0 交付时，因为全靠记忆更新文档，漏了操作手册与收尾交付说明两份，补完还得重走一遍构建+打包+280MB LFS 推送。清单化就是为了不再靠记忆。

---

## 0. 怎么用

- 按阶段顺序走，**不要跳步**。第 3 阶段（构建）失败时回头改代码，改完必须从第 2 阶段重来。
- 每项后面的「验证」列是**可执行的命令或动作**，不是"检查一下"这种空话。
- 打不了勾的项，写清原因和责任人，不要留空。

## 1. 阶段一：代码改完了吗

| # | 检查项 | 为什么 | 验证方式 |
|---|---|---|---|
| 1.1 | 版本号**三处**同改 | 只改一处会出现"装的是新版、显示是旧版"或门禁不过 | `package.json` 的 `version`、`assets/core.js` 的 `APP_VERSION`、`build.win.artifactName` 三处比对 |
| 1.2 | 新增账本数组加进 `COMPANY_KEYS` | 代理只认这 6 个键（`accounts/transactions/debts/settlements/budgets/categories`），新数组不加进去，`DB.xxx` 会静默 `undefined`，不报错、只出错数 | 搜 `COMPANY_KEYS`（core.js:197）看有没有漏 |
| 1.3 | 新增字段在 `normalize()` 里补了默认值 | 老数据文件不会带新字段，不补默认值会读出 `undefined` 再参与计算 → NaN | 用旧版 `data.json` 启动一次，看有没有 NaN |
| 1.4 | `noCash` 口径没有搞反 | 资金类（余额/净流入/现金流量/集团合并）**要过滤**；费用类（预算已用/项目支出/支出构成）**不能过滤**，过滤了会让预算虚低、超支提醒延迟 | 搜 `noCash` 全部命中点，逐个判断属于哪类 |
| 1.5 | 改聚合函数时没引入 O(n×m) | `companyBalanceAt` 若改成逐账户调 `balanceOf`，趋势图 200 点 × 3 万流水会卡死 | 趋势图切"本年"，看是否秒开 |
| 1.6 | 导入校验同时认新旧结构 | v5.0.0 踩过：`applyImport` 只认顶层 `data.accounts`，自己导出的 `{companies:[]}` 反而导不回来（P0） | 导出账套 → 立即导入 → 公司数/流水数/本位币不变 |
| 1.7 | 全量脚本语法通过 | 少个括号整个页面白屏 | `for f in assets/*.js electron/*.js; do node --check "$f"; done` |

## 3. 阶段三：构建与门禁

| # | 检查项 | 为什么 | 验证方式 |
|---|---|---|---|
| 3.1 | **在工作区外构建** | 工作区内 `electron-builder` 解包后要 `rename win-unpacked.tmp → win-unpacked`，而新生成的 `app.asar` 会被快照服务立刻独占 → `EPERM`。**这是必然失败，不是偶发** | 复制到 `%TEMP%\fm-build`，排除 `node_modules`/`dist`/`.git`/`.workbuddy-ai` |
| 3.2 | `node_modules` 用目录联接，不要复制 | 复制 455MB 太慢 | PowerShell `New-Item -ItemType Junction`。**不能用 `cmd /c mklink`**，会被安全策略拦 |
| 3.3 | 同步源码到构建目录时用 `-Path` 不用 `-LiteralPath` | `-LiteralPath` 不展开通配符，会静默不同步 | 同步后逐个 MD5 比对，必须全 same |
| 3.4 | 门禁 PASS | 结构断言 + 文本扫描 + 版本一致性 | `sh deliverables/pack-gate.sh dist`，要求 `asar=X exe=X`、0 告警 |
| 3.5 | 打包版真能启动 | 构建成功 ≠ 能运行 | `FUNDLEDGER_DATA_DIR=<临时目录> win-unpacked\合资金账.exe`，检查是否生成 `data.json` 且结构正常 |

### 5.2 操作手册是**双重身份**（v5.0.0 踩过）

`assets/manual.html`（软件内「使用手册」按钮打开的）与 `04-文档/操作手册.html` 是**同一份文件**，MD5 相同。

改手册必须走完这条链，缺一步装出来的软件里还是旧手册：

1. 改 `04-文档/操作手册.html`
2. 复制到 `assets/manual.html`
3. 复制到 `FundMerge-打包工程/assets/manual.html`
4. **重新构建**（手册在 `app.asar` 里）
5. 重打免安装版 zip
6. 网页版 `assets/manual.html` 覆盖
