# FundMerge 合资金账 · 打包工程

> 这是一个**可独立构建**的打包工程。双击 `build.bat` 即可生成 Windows 安装包。
> 对应版本：v5.2.0（2026-10-30）

---

## 一、这个目录里有什么

```

├─ package.json              版本 + electron-builder 配置
├─ index.html                应用入口
├─ assets/                   渲染层全部源码
│  ├─ core.js                数据模型 / 计算 / 鉴权
│  ├─ ui.js                  弹窗 / 图表 / 校验
│  ├─ views.js               20 个页面
│  ├─ modals.js              表单弹窗 / 导入导出 / 账套包
│  ├─ app.js                 登录 / 路由 / 主题 / 动效
│  ├─ scene.js               three.js 氛围层
│  ├─ styles.css             全部样式
│  ├─ manual.html            操作手册
│  └─ vendor/three.min.js    本地 three.js
├─ electron/
│  ├─ main.js                主进程（数据目录 / IPC / 文件归档 / 托盘）
│  ├─ preload.js             contextBridge
│  ├─ backup.js              云盘备份引擎（账套包版本池）
│  └─ flpack.js              账套包打包 / 解包
├─ build/
│  ├─ installer.nsh          安装器定制（卸载/升级保留 data）
│  └─ icon.*                 图标
└─ deliverables/
   ├─ pack-scan.js           发版门禁扫描器
   ├─ pack-scan.rules.json   规则（v4）
```

**没有 `node_modules`** —— 首次运行 `build.bat` 会自动 `npm install`（约 300MB，需联网一次）。

## 二、怎么构建

### 方式 A：双击（推荐）

双击 **`build.bat`**，它会自动完成：
1. 检查/安装依赖
2. 结束占用进程
3. 构建到 `dist/`
4. 跑发版门禁（PASS 才算成功）

### 方式 B：命令行

```bash
npm install
node node_modules/electron-builder/cli.js --win --x64 --config.directories.output=dist
```

**产物**：
```
dist/
├─ FundMerge-Setup-4.9.1.exe       ← 安装包，约 116MB
└─ win-unpacked/                    ← 免安装版，直接运行 合资金账.exe
```

---

## 三、构建前必须知道的 5 个坑

1. **先结束 `合资金账.exe`** —— 否则解包阶段 EBUSY。
2. **输出目录不能有 `win-unpacked.tmp` 残留** —— 会报 `[safe-delete] 操作失败`。换一个新的输出目录名（`dist2`、`dist3`…）。
3. **不要用 `mv`/`move` 替换产物目录** —— 文件系统视图延迟会误删。直接 `cp` 安装包。
4. **`build.productName` 与 `build.win.artifactName` 覆盖顶层同名配置** —— 只改顶层 `productName` 不生效。
5. **构建后别在 `win-unpacked` 里跑 exe** —— 会生成 `debug.log`，门禁会拦。

## 四、改版本号要改三处

| 文件 | 字段 |
|---|---|
| `package.json` | `version` |
| `assets/core.js` | `const APP_VERSION = 'x.y.z'` |
| `package.json` | `build.win.artifactName`（默认已含 `${version}`，一般不用动） |

## 五、发版门禁

```bash
sh deliverables/pack-gate.sh --self-test   # 验尺子（6 例）
sh deliverables/pack-gate.sh dist          # 验产物
```

退出码 0 才能发布。

门禁检查：
- **A 结构**：禁止 `data/`、`*.bak.json`、`debug.log`、开发文档出现在产物根目录
- **B 文本**：明文凭据、真实手机号、本机路径（解包 asar 后扫）
- **C 版本**：asar 内 version 必须等于 exe 版本

> ⚠️ 不要用 `node pack-scan.js dist | tail`，管道会吞掉退出码，导致「扫描失败但构建通过」。

## 六、代码签名

当前**未配置签名**，安装时会出现 SmartScreen「未知发布者」提示（点「更多信息 → 仍要运行」）。

如需签名，在 `package.json` 的 `build.win` 加：

```json
"certificateFile": "cert.pfx",
"certificatePassword": "从环境变量读取",
"rfc3161TimeStampServer": "http://timestamp.digicert.com"
```

或用环境变量 `CSC_LINK` / `CSC_KEY_PASSWORD`。

## 七、验证构建是否成功

```
□ dist/FundMerge-Setup-*.exe 存在，约 116MB
□ 双击安装，可选安装目录
□ 装完桌面有「合资金账」快捷方式
□ 首次启动出现「首次使用」页（设账号+口令+两个预留问题）
□ 安装根目录有：操作手册.html、开发交接说明.md、需求解读与实施方案.md、打包与发布说明.md
□ 门禁 PASS
```
