## 一、需求理解复述

这份文档不是增量补丁，而是一次**产品级重构**：把现有的「资金台账」升级为「合资金账 FundMerge」——
一个**多公司资金与档案管理平台**，并补上企业级系统必备的六类能力：

1. **安全底线**：危险操作双重校验、会话超时、账号密码可记住但必须加密、操作可追溯。
2. **权限纵深**：从"能登录就能看全部"变成"按公司授权、菜单/按钮/接口/数据四层同时管控"。
3. **数据可穿透**：任何一个数字都能点进去看到它是怎么算出来的、由哪些分公司构成。
4. **业务闭环**：借支备用金、票据未回、往来单位、凭证号——把财务日常真正跑起来。
5. **体验现代化**：主题、折叠、下钻、统一交互规范。
6. **数据安全**：云盘自动备份，凭据加密。

核心约束（贯穿全篇）：**所有删除要随机数字确认、所有统计要能下钻、所有改数据的操作要留日志、所有权限要四层同时生效**。

## 九、技术约束（改代码前必读）

- 完全离线是硬约束：任何联网功能必须**默认关闭**，且不破坏离线可用性。
- 渲染层无框架无构建，五个脚本顺序加载，不能引 ES module。
- 数据在 `<安装目录>\data`，`data.json` + `files/`，备份 = 复制整个文件夹。
- 内置最高管理员 `内置最高管理员账号（初始口令不入库、不入包）` 不可删除、不可降级。
- 破坏性操作必须 `requireCode: true`，新增删除入口时别忘了。
- 新页面统一用 `data-action` 事件委托，视图函数放 views.js，弹窗放 modals.js。

## 附录 D：需求 23 与需求 21 更新版（v4.8.0 / v4.9.x 交付）

### D.1 需求 23：账套整体打包与一键导入导出

**目标**：把一套完整账套打成**单一文件** `.flpack`，换电脑后一键导入完整恢复，不用手工复制 `data` 文件夹。

**账套包结构**（标准 ZIP，可用 7-Zip 打开）：

```
账套.flpack
├── manifest.json          格式版本 / 应用版本 / 导出时间 / 公司列表 / 统计 / 加密标记
├── ledger/data.json       账本主数据（公司/账户/流水/往来/预算/凭证/票据/借支/分类/项目）
├── ledger/data.bak.json   兜底副本
├── files/<公司ID>/<年月>/  全部附件
├── config/users.json      用户与权限（含密码哈希，不可逆）
├── config/system.json     货币 / 集团 / 凭证号规则 / 预算算法 / 主题偏好
├── config/cloud.json      云盘凭据（默认不含，勾选才带）
├── logs/audit.json        操作日志（可选）
└── checksum.sha256        逐文件 SHA-256
```

**导出**：设置 → 账套管理 → 导出账套。可选：是否包含操作日志、是否包含云盘凭据、是否设置加密口令、是否按公司导出（标记为部分账套）。

**导入**：设置页或**登录页**。流程：选文件 → 校验完整性/版本/密码 → 弹摘要（集团名/公司数/流水数/附件数/用户数/导出时间/软件版本/校验结果）→ 覆盖导入 → **随机数字二次确认** → 执行。

**回滚**：导入前先做 `.rollback-<时间戳>` 快照，写入失败自动还原，不留半套数据。

**加密**：`FLPK2` 头 + PBKDF2(120k) 派生密钥 + AES-256-GCM；明文包为 `FLPK1` + 裸 ZIP。

**自动备份**：启动后 15 秒检查，间隔 3 天，存 `%APPDATA%\FundLedger\autobackup\`，只保留最新 3 份。

**验收结果**：模块测试 20/20（打包/统计/合法 ZIP/解包/校验和/附件还原/日志/凭据剔除/加密/无密码/错密码/按公司/导入/回滚/损坏包）；端到端 12/13（唯一 FAIL 是 3 天间隔正确拒绝重复备份）。

### D.2 需求 21 更新版：云盘备份改为账套包版本池

**核心变更**：备份对象从「gzip 的 data.json + 附件」改为**完整账套包 `.flpack`**。

| 规则 | 实现 |
|---|---|
| 备份对象 | 完整账套包，不再备份散落 data 文件 |
| 手动备份 | 不看时间间隔，点即生成，标记「手动」 |
| 自动备份 | 按频率（每小时/6h/每天/每周/自定义），标记「自动」 |
| 版本池 | 手动+自动**统一池**，上限 **7 个**，超限删最旧（云端 DELETE + 索引移除） |
| 版本记录 | 编号 / 类型 / 时间 / 大小 / SHA-256 / 云盘路径 / 统计摘要 |
| 版本操作 | 恢复、下载、校验（SHA-256 + 包内 checksum 双验）、删除（随机码确认） |
| 本地可查 | 索引存 `%APPDATA%\FundLedger\backup-index.json`，云盘不可用也能看历史 |
| 凭据 | safeStorage 加密，配置文件无明文 |
