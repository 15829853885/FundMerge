# 合资金账 FundMerge · v5.5.5

面向中小企业的 Windows 桌面资金管理软件（现金 / 银行 / 往来 / 借支 / 票据 / 预算 / 多币种 / 集团合并）。

> **版本**：5.5.5 ｜ **发布日期**：2026-10-31 ｜ **上一版**：5.2.0
> **完全离线**：不联网也能用，数据只存本机

---

## 一、四种形态怎么选

| 目录 | 适合谁 | 怎么用 |
|---|---|---|
| **01-安装版** | 日常使用（推荐） | 双击 `FundMerge-Setup-5.5.5.exe` 安装，开始菜单/桌面会出现「合资金账」 |
| **02-免安装版** | 不想装、U 盘带走 | 解压 `合资金账-5.5.5-portable.zip`，双击其中的 `合资金账.exe` |
| **04-网页版** | 临时试用、开发调试 | 双击 `index.html`，用浏览器打开（数据存浏览器 localStorage） |
| **03-文档** | 所有人 | 操作手册、软件使用说明（通俗版）、全量测试报告、开发交接等（共 15 份） |

**数据位置**：安装版与免安装版都把账本存在 `%USERPROFILE%\Documents\资金台账\data.json`，两种形态共用同一份数据，可以随时互换。

## 二、更新了什么（v5.2.0 → v5.5.5）

### 票据资金流转（v5.3）

- 新增「票据未回资金」「未报账资金」两个系统账户，由票据动作自动生成与结转，不能手工操作；
- 记一笔支出可勾选「票据状态」：付款待票 → 整张回票 → 报账记费用，账面资金随报账才减少；
- 对账单新增「应付款项」。

### 动效与视觉（v5.4 / v5.5）

- 统一 3D 背景与页面入场动效，每页有专属过渡；
- 深色主题下动效清晰可见（投影 + 外发光双线索）；
- 新增指针反馈：卡片追光、指针光斑、粒子动效、点击波纹。

### 集团资金看板（v5.5）

- 新增「集团 → 资金看板」，实时展示公司间资金流向（每 5 秒自动刷新）；
- 卡片 / 丝带 / 圆环均可点击下钻到「流向明细」，逐笔查看。

### 修复与完善（v5.5.x）

- 两个系统账户改为只读，不出现在任何记账下拉；
- 集团总览「往来款预期/待处理」点击后正确跳转到对应公司；
- 修复内部转账转入账户余额不增加、可选数字字段误报等 5 个缺陷；
- 修复二次确认后弹窗不自动关闭的问题。

### 本次（v5.5.5）

- 设置页新增「更新历史」卡片，可随时查看历次版本；
- 重新设计软件图标，贴合「多公司资金合并管理」定位（不展示特定币种符号，适配多币种）；
- 重写操作手册，覆盖每个页面、每项功能与每条业务流程；
- 新增面向非技术人员的《软件使用说明（通俗版）》。

> 数据模型未变化，升级后旧账本直接可用，不需要迁移。
> 更早的版本演进（v1.0 → v5.5.5）见 `03-文档/开发报告.md` 与 `03-文档/全量测试报告.md`。

## 三、第一次使用

1. 安装（或解压免安装版）后启动，会进入**首次使用**页：设置管理员账号、口令、两个预留问题
   - 预留问题是忘记口令时的唯一找回通道，请认真填写
2. 进入「账户管理」建账户（现金 / 银行），填期初余额与日期
3. 到「设置 → 本位币与汇率」选本位币；有外币账户就录入汇率
4. 开始记账（「记一笔」或右上角快捷按钮）

**建议先做一次**：设置 → 导出 JSON 备份，养成习惯。
