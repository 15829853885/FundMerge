# 合资金账 FundMerge · v5.0.0 交付包

面向中小企业的 Windows 桌面资金管理软件（现金 / 银行 / 往来 / 借支 / 票据 / 预算 / 多币种 / 集团合并）。

> **版本**：5.0.0 ｜ **发布日期**：2026-10-29 ｜ **基线**：4.9.2
> **完全离线**：不联网也能用，数据只存本机

---

## 一、四种形态怎么选

| 目录 | 适合谁 | 怎么用 |
|---|---|---|
| **01-安装版** | 日常使用（推荐） | 双击 `FundMerge-Setup-5.0.0.exe` 安装，开始菜单/桌面会出现「合资金账」 |
| **02-免安装版** | 不想装、U 盘带走 | 解压 `合资金账-5.0.0-portable.zip`，双击其中的 `合资金账.exe` |
| **03-网页版** | 临时试用、开发调试 | 双击 `index.html`，用浏览器打开（数据存浏览器 localStorage） |
| **04-文档** | 所有人 | 交接说明、发布说明、需求方案、操作手册、测试报告 |

**数据位置**：安装版与免安装版都把账本存在 `%USERPROFILE%\Documents\资金台账\data.json`，两种形态共用同一份数据，可以随时互换。

## 二、v5.0.0 更新了什么

### 稳定性
- 修复**云盘备份页一进就卡死**（渲染与取数形成死循环）
- 修复**首次使用页反复弹出**（账号改名后被误判为新用户）
- 修复**导出的账套包无法导入恢复**（校验停留在旧结构，备份形同虚设）

### 数据正确性
- 修复「往来账款净额」下钻恒为 `NaN`
- 修复集团代付被多扣一倍，导致集团总额虚低
- 统一集团合并口径（8 处散落的「全部公司」改为「参与合并的公司」）
- 修复集团报表同页两套基准（卡片按今日、表体按区间）

### 新功能
- **多币种**：账户可挂不同币种，手动录入汇率，跨币种自动折算并标注原币；缺汇率时明确提示、不静默按 1:1
- **往来款支持币种**，跨币种结清自动折算
- **跨币种转账**支持单独填写「到账金额」
- **资金对账单**：总账面 = 现金 + 银行 + 票据未回 + 借款 + 借支备用金，每项可穿透
- **借支部分核销与撤销**、**票据快捷回票**、**账号卡片一次录入**
- **全面下钻**：集团/公司总览、集团报表、账户列表的指标都可点击查看明细，并自动带入筛选
- **台账筛选**：往来款、借支、票据支持日期范围 / 状态 / 关键字 + 分页
- **分级二次确认**：改金额、删除、改状态走随机数字确认；改备注走普通确认
- **操作日志**支持备注与逻辑删除

## 三、第一次使用

1. 安装（或解压免安装版）后启动，会进入**首次使用**页：设置管理员账号、口令、两个预留问题
   - 预留问题是忘记口令时的唯一找回通道，请认真填写
2. 进入「账户管理」建账户（现金 / 银行），填期初余额与日期
3. 到「设置 → 本位币与汇率」选本位币；有外币账户就录入汇率
4. 开始记账（「记一笔」或右上角快捷按钮）

**建议先做一次**：设置 → 导出 JSON 备份，养成习惯。
