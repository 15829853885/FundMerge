# 合资金账 FundMerge

> 多公司现金 / 银行存款资金管理桌面软件 · 支持集团合并 · 完全离线
> 版本 **v4.9.2** ｜ Windows 10 / 11 x64

一套账 = 一个文件。多家公司各自独立记账，集团层自动合并，换电脑只需导出一个 `.flpack` 账套包。

---

## 这是什么

给**一人管多家公司账**的场景做的资金流水工具。不是 ERP，不做会计凭证、不做总账、不做报表审计，只解决一件事：

> **钱从哪个账户进来、花到哪个项目上、现在还剩多少，以及集团层面一共多少。**

| 能力 | 说明 |
|---|---|
| 多公司独立账本 | 一个账号管 N 家公司，账本互不干扰，切换即换账 |
| 集团合并 | 总公司 + 分公司自动合并；总公司可配为「独立公司」或「仅登记主体」 |
| 资金流水 | 收 / 付 / 转三类；内部转账不计入收入支出，只改账户余额 |
| 往来款 | 借出 / 借入 / 未报销，结清时自动生成对应流水 |
| 预算 | 按月按分类设预算；支持按近 N 月自动生成（4 种算法 + 版本记录） |
| 项目 | 按项目归集资金使用，看预算执行率 |
| 报表 | 资金报表 + 集团报表 + 现金流量表（直接法，15 个项目） |
| 下钻 | 集团四个指标 → 分公司构成 → 明细 → 原始单据，全程面包屑 |
| 权限 | 超级管理员 / 管理员 / 记账员 / 只读；记账员按公司授权 |
| 审计 | 操作日志（12 类操作、5 维筛选、可导出），仅管理员可见 |
| 账套包 | `.flpack` 单一文件导出导入，可加密，SHA-256 逐文件校验 |
| 云盘备份 | WebDAV（坚果云/群晖/Nextcloud）+ Google Drive；手动/自动统一版本池，上限 7 个 |
| 离线 | 断网可用，零网络请求；云盘功能默认关闭 |

## 不做什么（明确的范围边界）

这一节比功能列表更重要，避免误期待。

| 不做 | 原因 |
|---|---|
| ❌ 实时协作 / 多人同时编辑 | 单机桌面架构，无服务端。做这个要先有服务端、账号体系、权限服务，是另一个产品 |
| ❌ 网盘多人同步 | 网盘无锁无事务，两台机器同时改同一份 `data.json` 必然互相覆盖。「看起来能用、实际会丢数据」的功能不做 |
| ❌ 手机 App / 手机浏览器 | 同上，需要服务端 |
| ❌ 会计凭证 / 总账 / 科目体系 | 定位是资金流水工具，不是财务核算系统 |
| ❌ 应用内自动更新 | 需更新服务器 + 代码签名；当前做法是覆盖安装，数据自动保留 |
| ❌ 降级保证 | 新版本字段旧版不认，升级前请先导出账套包 |
| ⚠️ 代码签名 | 未购买证书，安装时会弹 SmartScreen「未知发布者」，需点「更多信息 → 仍要运行」 |

## 安装与使用

### 方式一：安装版（推荐）

```
01-安装版/FundMerge-Setup-4.9.2.exe
```

- 装到当前用户目录，**不需要管理员权限**
- 创建桌面 / 开始菜单快捷方式
- **卸载不删数据**（`build/installer.nsh` 会把 `data` 目录移出再移回）
- 数据位置：`<安装目录>\data\`

### 方式二：免安装版

```
02-免安装版/FundMerge-4.9.2-portable/合资金账.exe
```

解压到任意可写目录直接双击。**不要放 `C:\Program Files\` 下**（无写权限会导致保存失败）。

### 方式三：网页版（仅演示）

```
03-网页版/index.html
```

双击即用，数据存浏览器 `localStorage`。业务功能齐全，但**不支持**账套包、云盘备份、附件上传、托盘。

### 首次启动

1. 用内置最高管理员账号登录，**强制设置新口令**（初始口令不入库、不入包）
2. 建公司 → 建账户（填期初余额）→ 建分类
3. 开始记账

详细操作见 `04-文档/操作手册.html`。

## 账套包与备份规则

### 账套包是唯一数据标准

```
账套.flpack  （标准 ZIP，可用 7-Zip 打开）
├── manifest.json          格式版本 / 应用版本 / 导出时间 / 公司列表 / 统计 / 加密标记
├── ledger/data.json       账本主数据
├── ledger/data.bak.json   兜底副本
├── files/<公司ID>/<年月>/  全部附件
├── config/users.json      用户与权限（密码哈希，不可逆）
├── config/system.json     货币 / 集团 / 凭证号规则 / 预算算法
├── config/cloud.json      云盘凭据（默认不含）
├── logs/audit.json        操作日志（可选）
└── checksum.sha256        逐文件 SHA-256
```

换电脑、备份、交接、归档**全部走这一个文件**。

### 云盘备份：7 版本池

| 规则 | 值 |
|---|---|
| 备份对象 | 完整 `.flpack` |
| 手动 / 自动 | **同一个池**，分别标记 |
| 上限 | **7 个**，超限删最旧 |
| 恢复校验 | SHA-256 + 包内 checksum **双验** |
| 本地索引 | `%APPDATA%\FundLedger\backup-index.json`，云盘连不上也能看历史 |
| 凭据 | safeStorage（Windows DPAPI）加密，配置无明文 |

> **坚果云必须用「应用密码」**（网页版 → 账户信息 → 安全选项 → 添加应用密码）。用登录密码会返回 401。

### 两条操作纪律

1. **升级前先导出账套包。**
2. **不要把 `data` 目录放进任何自动同步盘**（OneDrive / 坚果云同步文件夹 / Dropbox）——同步客户端会在写入中途上传，可能拿到半个 JSON。

```
├── electron/
│   ├── main.js      主进程：原子写 / 备份 / 云盘 / 升级恢复
│   ├── preload.js   contextBridge 暴露 window.desktop
│   ├── flpack.js    账套包：手写 ZIP + CRC32 + AES-256-GCM

├── build/
│   ├── installer.nsh  卸载保留数据
│   └── icon.ico

```

**脚本加载顺序固定**（`file://` 不支持 ES module）：
`core.js → ui.js → views.js → modals.js → vendor/three.min.js → scene.js → app.js`

构建：

```bash
npm install
npm run dist     # → dist/FundMerge-Setup-<ver>.exe
```

| 项目 | 结果 |
|---|---|
| 最终全量测试（56 例） | **49 通过**；7 例失败经复测均为脚本问题，非产品缺陷 |
| 离线能力审计 | **21/21 通过**，零网络请求 |
| 账套包模块测试 | 20/20 通过 |
| 账套包端到端 | 12/13（唯一 FAIL 是「3 天内重复自动备份被正确拒绝」，预期行为） |
| 坚果云 WebDAV 实测 | 5/5 通过 |
| 云盘 7 版本池实测 | 连续 8 次备份 → 云端恰好 7 个，最旧自动删除 |
| 动效验证 | 18 项通过，无卡顿 |

| 红线 R3（数据损坏） | 通过：从 `data.bak.json` 恢复 27 笔流水 |

### 能力上限

| 维度 | 上限 | 卡在哪 |
|---|---|---|
| 流水条数 | ~100 万 | 单文件 JSON 全量载入内存 |
| 操作日志 | ~200 万 | 同上 |
| 附件 | ~2 万 / 20 GB | 磁盘 + 打包时间 |
| 同时使用人数 | 5–10（轮流） | 单机无服务端 |

到上限后建议**按年度切账套**，旧年度只读归档。

### 未验证项

8 小时挂机 · Windows 10 实机 · 125%/150% 系统缩放 · 真实打印机 · Google Drive 真实授权（缺 OAuth 客户端）· 双实例并发写 · 权限 5 角色 × 9 操作完整矩阵。

### 已知功能缺口

1. 需求 11：集团查看/修改分公司项目（项目页只看当前公司）
2. 账套包「作为新账套导入」——后端已实现，UI 无入口（当前只能覆盖导入）
3. 按公司导出（部分账套）——后端有 `partial` 标记，UI 无勾选

## 技术栈

Electron 45 · 原生 HTML/CSS/JS（**无框架、无构建、无 CDN 依赖**）· 手写 ZIP + CRC32 · PBKDF2-SHA256 · AES-256-GCM · safeStorage · electron-builder NSIS

渲染层刻意不引框架：`file://` 协议不支持 ES module，且离线可用是硬约束（不能有任何 CDN 请求）。图表用原生 SVG 生成字符串，3D 用本地打包的 three.js。
