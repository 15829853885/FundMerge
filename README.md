# 合资金账 FundMerge · v5.5.8

面向中小企业的 Windows 桌面资金管理软件（现金 / 银行 / 往来 / 借支 / 票据 / 预算 / 多币种 / 集团合并）。

> **版本**：5.5.8 ｜ **发布日期**：2026-11-01 ｜ **上一版**：5.5.5
> **完全离线**：不联网也能用，数据只存本机

---

## 一、四种形态怎么选

| 目录 | 适合谁 | 怎么用 |
|---|---|---|
| **01-安装版** | 日常使用（推荐） | 双击 `FundMerge-Setup-5.5.8.exe` 安装，开始菜单/桌面会出现「合资金账」 |
| **02-免安装版** | 不想装、U 盘带走 | 解压 `合资金账-5.5.8-portable.zip`，双击其中的 `合资金账.exe`（内含「升级须知.txt」） |
| **04-网页版** | 临时试用、开发调试 | 双击 `index.html`，用浏览器打开（数据存浏览器 localStorage） |
| **03-文档** | 所有人 | 操作手册、软件使用说明（通俗版）、全量测试报告、桌面版测试清单、开发交接等（共 16 份） |

**数据位置**：账本默认存在程序所在目录的 `data\` 子文件夹（安装版=安装目录下、免安装版=解压目录下）；若该目录不可写（例如把安装版装到了 `Program Files`），会自动回落到「文档\资金台账」。升级或重装前建议先备份 `data` 文件夹。

## 二、更新了什么（v5.5.5 → v5.5.8）

### 本次修复（v5.5.8）

- **修复账套包导入后数据未变化的缺陷**：旧版用「账套包」恢复数据时提示「导入成功」，但账户、流水、期初余额、往来单位等仍是旧数据（根因：主进程写入新数据后，又被界面用旧数据覆盖）；
- **修复「云盘恢复」同类的覆盖问题**；
- **免安装版新增升级提示**：`升级须知.txt` 提醒覆盖解压升级前先备份 `data` 目录。

### 上一版（v5.5.5）

- 设置页新增「更新历史」卡片，可随时查看历次版本；
- 重新设计软件图标（不展示特定币种符号，适配多币种）；
- 重写操作手册，覆盖每个页面、每项功能与每条业务流程；
- 新增面向非技术人员的《软件使用说明（通俗版）》。

### 更早（v5.3 / v5.4 / v5.5）

- 票据资金流转（票据未回 / 未报账两个系统账户，随票据自动结转）；
- 3D 动效体系 + 深色主题动效可见性 + 指针反馈与粒子动效；
- 集团资金看板（实时资金流向，卡片/丝带/圆环可下钻）。

> 数据模型未变化，升级后旧账本直接可用，不需要迁移。
> 完整的版本演进（v1.0 → v5.5.8）见 `03-文档/开发报告.md`、`03-文档/全量测试报告.md` 与 `03-文档/桌面版测试清单.md`。

## 三、第一次使用

1. 安装（或解压免安装版）后启动，会进入**首次使用**页：设置管理员账号、口令、两个预留问题
   - 预留问题是忘记口令时的唯一找回通道，请认真填写
2. 进入「账户管理」建账户（现金 / 银行），填期初余额与日期
3. 到「设置 → 本位币与汇率」选本位币；有外币账户就录入汇率
4. 开始记账（「记一笔」或右上角快捷按钮）

**建议先做一次**：设置 → 导出 JSON 备份，养成习惯。
