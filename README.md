# 合资金账 FundMerge · v5.5.10

面向中小企业的 Windows 桌面资金管理软件（现金 / 银行 / 往来 / 借支 / 票据 / 预算 / 多币种 / 集团合并）。

> **版本**：5.5.10 ｜ **发布日期**：2026-11-02 ｜ **上一版**：5.5.9
> **完全离线**：不联网也能用，数据只存本机

---

## 一、四种形态怎么选

| 目录 | 适合谁 | 怎么用 |
|---|---|---|
| **01-安装版** | 日常使用（推荐） | 双击 `FundMerge-Setup-5.5.10.exe` 安装，开始菜单/桌面会出现「合资金账」 |
| **02-免安装版** | 不想装、U 盘带走 | 解压 `合资金账-5.5.10-portable.zip`，双击其中的 `合资金账.exe`（内含「升级须知.txt」） |
| **04-网页版** | 临时试用、开发调试 | 双击 `index.html`，用浏览器打开（数据存浏览器 localStorage） |
| **03-文档** | 所有人 | 操作手册、软件使用说明（通俗版）、全量测试报告、桌面版测试清单、开发交接等（共 16 份） |

**数据位置**：账本默认存在程序所在目录的 `data\` 子文件夹（安装版=安装目录下、免安装版=解压目录下）；若该目录不可写（例如把安装版装到了 `Program Files`），会自动回落到「文档\资金台账」。升级或重装前建议先备份 `data` 文件夹。

## 二、更新了什么（v5.5.9 → v5.5.10）

### 本次变更（v5.5.10）

- **版本号统一为 5.5.10**：安装包文件名、asar 内版本、exe 文件资源、全部文档四处一致，解决此前「包名 / 界面 / 文档」版本标注不齐的问题；
- **无业务逻辑改动**：功能与 5.5.9 完全相同；
- 运行时保持 **Electron 45.1.0**，安装版与免安装版均重跑 23 项真机冒烟（启动/首启/登录/记账/多选批量删除/主题/控制台）全通过；
- 账本 `data.json`、账套包 `.flpack`、导出 JSON 格式未变，5.5.9 及更早版本数据可直接沿用。

### 上一版（v5.5.9）

**所有可删除的列表都支持多选批量删除**，覆盖 10 个页面：

| 页面 | 批量删除时的约束（与单条删除一致） |
|---|---|
| 资金流水 | 仅管理员；票据自动生成的分录不可删（需到票据页撤销） |
| 往来款 | 连带删除该笔的分期结清记录 |
| 账户管理 | 系统账户不可删；已有流水的账户不可删（可停用） |
| 分类管理 | 已被流水使用的分类只能停用 |
| 用户管理 | 内置管理员、当前登录账号、最后一名管理员不可删 |
| 公司管理 | 至少保留一家公司 |
| 往来单位 | 已被引用的只能停用 |
| 借支备用金 | 有未核销余额的按原规则拦截 |
| 票据未回 | 已报账的需先撤销；删除时冲销关联流水 |
| 项目 | 已有流水的项目不可删 |

使用方式：勾选行首复选框（表头可全选本页）→ 顶部出现「已选 N 条」→ 点「批量删除」→ 输入 4 位随机验证码确认。不可删除的行复选框为禁用态；批量执行中遇到不可删记录会**跳过并提示原因**。

### 更早（v5.5.8 / v5.5.5 / v5.5）

- v5.5.8：修复账套包导入后数据未变化的缺陷（主进程写入新数据后又被界面旧数据覆盖）；修复「云盘恢复」同类问题；免安装版新增 `升级须知.txt`；
- v5.5.5：设置页「更新历史」卡片；重绘软件图标（不展示币种符号）；重写操作手册，新增《软件使用说明（通俗版）》；
- v5.5：票据资金流转（票据未回 / 未报账两个系统账户，随票据自动结转）；3D 动效体系；集团资金看板（卡片/丝带/圆环可下钻）。

> 数据模型未变化，升级后旧账本直接可用，不需要迁移。
> 完整的版本演进（v1.0 → v5.5.10）见 `03-文档/开发报告.md`、`03-文档/全量测试报告.md` 与 `03-文档/桌面版测试清单.md`。

## 三、第一次使用

1. 安装（或解压免安装版）后启动，会进入**首次使用**页：设置管理员账号、口令、两个预留问题
   - 预留问题是忘记口令时的唯一找回通道，请认真填写
2. 进入「账户管理」建账户（现金 / 银行），填期初余额与日期
3. 到「设置 → 本位币与汇率」选本位币；有外币账户就录入汇率
4. 开始记账（「记一笔」或右上角快捷按钮）

**建议先做一次**：设置 → 导出 JSON 备份，养成习惯。
