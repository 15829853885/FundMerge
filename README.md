# 合资金账 FundMerge · v5.2.0

面向中小企业的 Windows 桌面资金管理软件（现金 / 银行 / 往来 / 借支 / 票据 / 预算 / 多币种 / 集团合并）。

> **版本**：5.2.0 ｜ **发布日期**：2026-10-30 ｜ **上一版**：5.0.1
> **完全离线**：不联网也能用，数据只存本机

---

## 一、四种形态怎么选

| 目录 | 适合谁 | 怎么用 |
|---|---|---|
| **01-安装版** | 日常使用（推荐） | 双击 `FundMerge-Setup-5.2.0.exe` 安装，开始菜单/桌面会出现「合资金账」 |
| **02-免安装版** | 不想装、U 盘带走 | 解压 `合资金账-5.2.0-portable.zip`，双击其中的 `合资金账.exe` |
| **03-网页版** | 临时试用、开发调试 | 双击 `index.html`，用浏览器打开（数据存浏览器 localStorage） |
| **04-文档** | 所有人 | 操作手册、开发交接、需求解读、打包发布、构建说明、开发报告、测试报告、交付前必改清单、开发心路历程、收尾交付说明（共 10 份） |

## 二、更新了什么（v5.0.1 → v5.2.0）

### 数据正确性（本次重点）

| 修复 | 说明 |
|---|---|
| **找不到账户的流水不再按 1:1 折算** | 以前这类流水的币种会被当成"本位币"，金额直接按原数计入合计——多币种账套会静默算错（汇率 > 1 少计、< 1 多计）。现在一律**从合计中排除**，并在页面顶部提示「有 N 笔流水找不到所属账户」，点「查看流水」直接跳过去处理 |
| **账户缺标识不再被丢弃** | 归一化时账户缺 id 以前是直接丢弃（连带它的流水变成孤儿），现在自动补标识；被跳过的流水也会计数提示，不再静默消失 |
| **导入账套前先预检** | 选中账套包后，摘要弹窗会列出公司数、**账户数**、流水数、附件、用户，并在发现「缺标识的账户 / 找不到归属的流水 / 会被跳过的流水」时给出橙色提醒——**此时点「取消」不会改动任何数据** |
| **移除未完成的「追加为新账套」导入分支** | 该分支从未接入界面，且给主键加后缀后没有同步重写流水里的账户引用，留着比删掉更危险，已整段移除。导入只保留「覆盖」一种方式（导入前自动做回滚备份） |

### 登录与权限

| 变化 | 说明 |
|---|---|
| **登录身份改为下拉** | 顺序为 记账员 → 查看员 → 管理员（管理员固定最后一项）。系统按账号记住上次选择；首次登录某账号会自动预置该账号的真实身份；手动改过之后不再被自动覆盖 |
| **注册可选用户类型** | 注册页新增「注册用户类型」，只能选 记账员 或 查看员；不选或传入非法值会提示错误并阻止提交。管理员仍需由管理员在「用户管理」里创建或改派 |
| **新增「查看员」只读角色** | 可查看全部页面与报表、可导出，但不能新增/编辑/删除任何数据：写按钮显示为禁用并提示「查看员为只读权限」，即使绕过界面触发也会被拦截 |
| **修掉三处权限与数据缺陷** | ① 用户管理保存时会把「查看员」静默降级成「记账员」并给写权限；② 自我降权/停用的守卫晚于赋值，内存已改、后续保存会静默生效；③ 缺 id 的历史用户无法编辑/重置密码/删除 |

### 体验与无障碍

- 错误提示条加 `role="alert"`，出错时自动滚动到提示并把焦点落到出错字段
- 登录/注册页的输入框与下拉统一 40px 高（修掉一条写了却从未生效的 CSS 规则）
- 认证表单 22 处嵌套 `<label>` 改为合规结构，读屏更稳
- 登录公司下拉在账号未识别前禁用，少一个空的 Tab 停靠点

> 数据模型未变化，升级后旧账本直接可用，不需要迁移。
> 更早的版本演进（v1.0 → v5.0.1，34 个版本逐个复盘）见 `04-文档/开发报告.md`。

## 三、第一次使用

1. 安装（或解压免安装版）后启动，会进入**首次使用**页：设置管理员账号、口令、两个预留问题
   - 预留问题是忘记口令时的唯一找回通道，请认真填写
2. 进入「账户管理」建账户（现金 / 银行），填期初余额与日期
3. 到「设置 → 本位币与汇率」选本位币；有外币账户就录入汇率
4. 开始记账（「记一笔」或右上角快捷按钮）

**建议先做一次**：设置 → 导出 JSON 备份，养成习惯。
